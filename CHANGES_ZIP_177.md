# Zip 177 — public website, sign-up hardening, SEO, offers

## You asked: "ensure log in works both online and offline"
* Till/app sign-in is checked **on the device** (password hash in local storage), so it works with no internet in every module. New test `tests/login-online-offline.test.mjs` signs in to all 7 apps with the network down and up, and checks a wrong password is refused (14 tests).
* The website **dashboard** needs a server. It now says so plainly when offline, and a dropped connection no longer wipes the saved website sign-in (it used to clear the token on any error).
* Signing in on a **brand-new device** still needs internet once (it has to fetch the shop). That cannot work offline by design.

## Public website
* New pages with one design (`public-site/site.css`): **Terms, Privacy, Cookies, Acceptable Use, FAQ, Contact, Offers**, generated by `npm run build:public` (a test fails if they drift). Product pages at `/products/<key>`.
* Home: nav + footer links, canonical/OG/Twitter, JSON-LD (Organization, WebSite; FAQPage on /faq), favicon, `og-default.png`, offers strip with live countdown. The fixed "no monthly fees" claims now follow the price plan set in the Owner Console.
* `robots.txt`, `sitemap.xml`, `llms.txt` (apex only; client hosts are `Disallow: /`), branded `404.html` (+ `errors/403,429,500.html`).
* Cookieless first-party page counts (`/api/hit`, honours Do-Not-Track).

## Accounts and security
* PBKDF2-SHA256 (100k, Workers' maximum) for website, owner and recovery passwords; old hashes upgrade on login. 8+ character rule for website sign-up/reset.
* Terms/Privacy consent required at website **and** POS sign-up; version + time stored.
* Email or WhatsApp one-time code (`/api/verify`), dashboard panel; `VERIFICATION_REQUIRED=1` optional.
* Contact form with honeypot, fill-time check, per-IP limit, optional Turnstile.
* Security headers in `_headers`; noindex on all private apps (header + meta); `nosniff` on `/api`.
* Owner Console ▸ 🏷️ **Offers**: draft/published/paused/archived, status computed on the server clock (Nairobi), audit log.
