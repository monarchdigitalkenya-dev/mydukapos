## How to reconcile one

1. Diff the variants (the groups above tell you which apps to compare).
2. Decide the intended behaviour; where apps genuinely differ, express the difference as a small per-app setting rather than a forked function.
3. Put the single version in `src/shared/functions.js` (`//@fn name`), add `name` to each app's `@shared:begin names=…` list, delete that app's local copy.
4. `npm run sync && npm run check`, then test in the affected apps.
