# Zip 164 (hotel)
- 💰 **Sales** button next to 🧾 Bills on the Sales Counter: Total / Cash / M-Pesa (Card only when there is some) for a chosen day (today by default). Staff see only their own sales; the admin sees everyone plus one block per server. Voided sales are left out.
- ▲ **Hide** in the top bar folds the header away, leaving a slim ▼ bar; ▼ shows it again. It only changes when you press the button (no automatic re-show) and is remembered on that device.
