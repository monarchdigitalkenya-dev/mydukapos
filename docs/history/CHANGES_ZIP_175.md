# Zip 175 — order ticket back to normal spacing, least possible paper
Zip 174's wider line spacing is removed: the ticket prints with its normal compact lines again. The page is now exactly square (80 x 80 mm on an 80 mm roll, 58 x 58 on a 58 mm roll; it was 2 mm longer) - the shortest page that is still portrait, so the printer does not turn a short ticket sideways. Long tickets are unchanged.
Stamp zip-175. No migration; workflows and native/ unchanged.
