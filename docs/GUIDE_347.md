# Guide - zip 347: when a password does not work

**What was wrong:** after the owner reset a password in the Owner Console, some phones kept the old password until they synced, and in one case an old phone could put the old password back. Now the login asks the server directly, ignores spaces at the end, and an old phone can no longer undo a reset.

**To reset a password (owner):**
1. Open the Owner Console and pick the shop.
2. Press Reset password. Choose "both" if people cannot open the app and also cannot reach Management.
3. Send the temporary password (8 letters and numbers) to the user. Capital and small letters matter.
4. The user types it at the login screen. If the phone has internet, it works within a few seconds.
5. Tell the user to set their own password afterwards in Settings.

**If a user is still stuck:** make sure the phone has internet, close the app fully and open it again, then type the temporary password. Do not type old passwords many times.
